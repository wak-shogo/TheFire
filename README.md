# TheFire

スマホで動作する、リアルタイム物理流体シミュレーション焚き火。

🌐 **GitHub Pages**: https://wak-shogo.github.io/TheFire/

## 特長

- **リアルタイム流体・燃焼シミュレーション**（WebGL2 / WebGL1）：浮力・渦度閉じ込め（Vorticity Confinement）・非圧縮圧力投影・Clamped MacCormack 移流・放射冷却・火の粉パーティクル・薪と熾火をリアルタイムに計算。
- **ウルトラシンプルな UI**：基本は全画面の焚き火のみ。右上のハンバーガーメニューから以下の設定をリアルタイムに調整可能。
  - **色**：6種類のプリセット＋カスタムカラー
  - **勢い**：炎の高さ・ゆらぎ・火の粉の勢い
  - **最大 / 最小の明るさ**：自然な明滅レンジと最大輝度の上限
  - **フェードアウト時間**：タイマーで炎→熾火→消火へ自然にフェードアウト（消火後は画面タップで再点火）
- **スマホ最適化**：画面スワイプで炎をかき混ぜるインタラクション、Wake Lock API によるスリープ防止（消火後は自動解除）、ホーム画面追加（PWA）対応。
