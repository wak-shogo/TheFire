# TheFire

スマホで動作する、リアルタイム物理流体シミュレーション＆1/fゆらぎ焚き火。

🌐 **GitHub Pages**: https://wak-shogo.github.io/TheFire/

## 特長

- **人スケールの焚き火シミュレーション**（WebGL2 / WebGL1）：浮力・空気の巻き込み・渦度閉じ込め・圧力投影・Clamped MacCormack 移流・発熱燃焼・$T^3$ 放射冷却をリアルタイム計算し、7オクターブの **1/fゆらぎ（ピンクノイズ）** で炎の舌・風・明るさを有機的に駆動します。
- **ウルトラシンプルな UI**：基本は全画面の焚き火のみ。右上のハンバーガーメニューから広範囲に調整可能。
  - **色**：6種類のプリセット＋自由なカラーピッカー
  - **勢い**：`1%〜150%`（種火の揺らぎから大きなキャンプファイヤーまで）
  - **タイムスケール**：`0.05×〜8.0×`（超スローモーションから高速なパチパチ揺らぎまで対数スケールで調整）
  - **カメラ距離**：`0.25m〜4.00m`（至近距離で炎に包まれる視点から遠くの焚き火まで／2本指ピンチでも操作可能）
  - **最大 / 最小の明るさ**：`0%〜150%`（自然な明滅レンジと輝度上限）
  - **フェードアウト時間**：`なし〜180分`（炎 → 熾火 → 消火と自然に減衰。消火後は画面タップで再点火）
- **スマホ最適化**：画面スワイプで炎をかき混ぜる操作、2本指ピンチでカメラ距離調整、Wake Lock API によるスリープ防止、ホーム画面追加（PWA）対応。
